# UI QA Checklist

## Information Architecture

- [ ] User understands the page purpose immediately
- [ ] Primary navigation is obvious
- [ ] Tools are easy to discover
- [ ] Categories are clear
- [ ] Intent filters make sense

## Tool Cards

- [ ] Name is prominent
- [ ] Description is readable
- [ ] Status is obvious
- [ ] Metadata is secondary
- [ ] CTA is clear
- [ ] Entire card has predictable interaction

## Responsive

- [ ] No horizontal overflow
- [ ] Header works on mobile
- [ ] Filters work on mobile
- [ ] Cards remain readable
- [ ] Typography scales correctly
- [ ] Touch targets are adequate

## Accessibility

- [ ] Keyboard navigation works
- [ ] Focus states are visible
- [ ] Heading hierarchy is correct
- [ ] Contrast is sufficient
- [ ] Status does not depend on color
- [ ] Reduced motion works

## Visual Quality

- [ ] No unnecessary gradients
- [ ] No excessive shadows
- [ ] No random icon styles
- [ ] Spacing is consistent
- [ ] Typography is consistent
- [ ] Components share the same visual language
- [ ] Design feels institutional and modern

## Final Test

The interface should feel like a serious operational platform, not a generic AI website.
