# Design System Reference

## Visual Character

The target aesthetic sits between:

Government editorial design
+
Modern defense technology
+
Enterprise software

The interface should feel deliberate rather than flashy.

## Layout

Prefer:

- Strong alignment
- Generous whitespace
- Wide editorial containers
- Clear vertical rhythm
- Intentional section breaks
- Dense information only where useful

Avoid:

- Random card mosaics
- Excessive centered content
- Unnecessary full-screen heroes
- Decoration that competes with content

## Borders and Surfaces

Prefer thin, restrained borders and subtle surface differentiation.

Cards should feel like parts of one information system rather than isolated floating objects.

## Cards

A card should have a clear visual sequence:

1. Category/status
2. Name
3. Description
4. Metadata
5. Action

The entire card can be clickable when appropriate.

## Editorial Rhythm

Large sections should have:

- Section identifier
- Title
- Short explanation
- Divider
- Content grid/list

This creates the institutional rhythm seen in strong editorial websites.

## Imagery

Only use imagery when it adds meaning.

Prefer authentic mission, Air Force, technology, aircraft, or operational imagery.

Avoid generic AI stock photography.

## Icons

Use one consistent icon system.

Good candidates:

- Lucide
- Phosphor
- Heroicons

Do not mix unrelated icon styles.

## Interaction

Every interactive element needs:

- Default
- Hover
- Active
- Focus

States should be obvious without being theatrical.

## Design Principle

If an element can communicate its purpose through typography, spacing, hierarchy, or composition, prefer that over decorative effects.
