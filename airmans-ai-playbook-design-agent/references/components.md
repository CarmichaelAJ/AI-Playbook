# Component Reference

## SiteHeader

Responsibilities:
- Brand identity
- Primary navigation
- Search
- Mobile menu
- Active state

## PageHero

Responsibilities:
- Eyebrow
- Page title
- Description
- Search or primary action
- Metadata

## IntentFilters

Responsibilities:
- Task-based discovery
- Active filter
- Keyboard interaction
- Mobile behavior

Examples:
Write, Research, Track Data, Automate, Dashboard, Form

## ToolDirectory

Responsibilities:
- Filtering
- Category grouping
- Empty states
- Tool count
- Responsive grid/list

## ToolCategory

Responsibilities:
- Number/identifier
- Category title
- Description
- Divider
- Tool collection

## ToolCard

Responsibilities:
- Tool name
- Description
- Status
- Metadata
- Primary CTA

## StatusBadge

Must not rely on color alone.

Examples:
Approved, M365, Coming Soon, Verified, Review Required

## WorkflowDiagram

Show relationships between tools/workflows clearly.

Do not turn it into a decorative infographic.

## OpsecNotice

Present important usage guidance clearly and prominently without making the page feel alarmist.

## SiteFooter

Provide concise ecosystem navigation and supporting links.
